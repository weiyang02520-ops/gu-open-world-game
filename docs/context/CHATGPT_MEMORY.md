# ChatGPT Memory

## 用户目标

制作一个《蛊真人》世界观下的开放世界模拟 RPG。玩家是自创蛊师，原作人物和势力作为 NPC 与世界组成部分存在；局部世界线可以因玩家行为偏移。

## 设计原则

- 小地图、完整规则闭环，先做 10 个游戏日的 V0.1 Vertical Slice。
- Canon 与游戏扩展分层；每条事实保留 provenance 和证据级别。
- 外部 ChatGPT 负责方向、审查和 Gate；Codex 负责仓库实现、测试和交接。
- 每个 Milestone 完成后停下，不把计划写成已实现。
