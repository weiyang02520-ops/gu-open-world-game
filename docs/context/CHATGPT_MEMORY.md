# ChatGPT Memory

## Project goal

高开放度《蛊真人》世界模拟 RPG。玩家是自创蛊师，世界中的 NPC、经济、战斗、信息与势力通过统一规则自行演化；原作剧情不是强制主线。

## Stable principles

- 小区域深系统优先。
- Player/NPC共享核心规则。
- Canon Database 与动态 World State 分离。
- NPC 不读隐藏 WorldTruth。
- 不用单一 Character EXP。
- 不用单一 Reputation 数值概括社会关系。
- 大任务包开发，重大 Milestone 人工 Gate。
