# TASK-V0.1.2-BASIC-UI

## 目标

将当前 V0.1 终端试玩版升级为基础可视化原型。

原则：不做 3D，不追求重美术，优先实现可玩的 2D UI 体验。

目标体验：

创建蛊师 → 查看状态 → 点击行动 → 触发事件 → 查看结果 → 推进世界。

---

# 1. 技术方向

推荐：

- Web UI 或轻量桌面 UI
- 与现有 Python 游戏核心解耦
- UI 只负责展示和输入
- 游戏逻辑继续由 gu_game 核心负责

禁止：

- 重写核心模拟
- 将逻辑写入 UI 层
- 引入高成本 3D 引擎

---

# 2. UI结构

## 主界面

- 玩家状态栏

# 8. 接口要求

必须通过接口：

- 获取状态
- 提交行动
- 推进 Tick
- 保存加载
